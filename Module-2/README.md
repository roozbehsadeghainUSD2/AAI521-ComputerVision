Introduction
In this module, we will see the Convolutional Neural Network (CNN) as one of the most important algorithms in computer vision. We started our introduction to machine learning and neural networks in the last module, but in this module, we will expand our discussion to using deep learning approaches in image processing applications. We will focus on several real-world examples and scenarios.

## Learning Outcomes
- Practice deep learning and CNN algorithm and its applications.
- Develop CNN models on image processing.
- Describe the idea of overfitting and underfitting in deep learning models.
- Develop pre-trained models.
- Research and determine a technical approach for a novel computer vision problem for a team project.
