# Module 5- Real-Time Analysis, Video Handling, and Motion Detection 
In this module, you will be introduced to processing across multiple images including image alignment and registration, processing video images, and problems of motion estimation. The techniques in this module are important for applications such as self-driving cars or real-time monitoring. In this module, you will use some sections from the textbook, but you will also rely on tools from the OpenCV a bit more.

## Learning Outcomes
- Develop programs that align multiple images.
- Apply computer vision algorithms to video.
- Implement systems that estimate motion from video or a series of images.
- Develop real-time processing algorithms and motion detection.
