# AAI521-ComputerVision
Welcome to the AAI-521 Applied Computer Vision for AI course! In the first module, you will get an overview of the course and the field of computer vision as we cover the foundations, history, and current state-of-the-art of the field of computer vision. You will also get an overview of the physics of image formation, image capture, image processing, pattern recognition, machine learning, and applications as applied to computer vision. You will become familiar with image pre-processing and how to incorporate the Pillow package in Python for preparing images for further analysis. We will also have a brief introduction to the elements of a neural network. It is a project-based course with many hands-on assignments in each module. 

Note that through different modules in this course, selected free media and readings from additional sources might be offered to further support your online learning outcomes. Enjoy the course!  

## Learning Outcomes
- Describe the common applications of computer vision.
- Set up tools and a work environment for developing computer vision programs.
- Describe and perform the pre-processing procedure in an image.
- Describe and perform the processing procedure in image.
- Define the elements of a neural network.
- Build and test neural network models.
