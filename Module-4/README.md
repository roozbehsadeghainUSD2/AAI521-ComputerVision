# Module 4: Advanced Vision Problems, Feature Extraction, Parameter Detection, and Facial Recognition
In this Module, our focus will be on more advanced vision problems. You will accomplish two significant things. First, you will learn how to detect and identify features, edges, and contours in images. Second, we will discuss how to identify the parameters of the image and its applications. Finally, you will learn how to map out and plan a specific computer vision named facial recognition in some detail. This includes objective identification, data needs identification, matching algorithms and tools to the problem at hand, implementation and testing of successive prototypes, and performance evaluation.

## Learning Outcomes
- Discuss the feature extraction methods and the parameters associated with images.
- Develop algorithms and programs that extract features from images and identify simple objects.
- Implement machine learning and deep learning algorithms for parameter detection.
- Discuss how to design and implement a facial recognition system.
