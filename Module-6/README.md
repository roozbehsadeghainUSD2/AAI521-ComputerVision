# Module 6- Image Generation, GANs, Managing Machine Vision Projects
In this module, you will be introduced to Generative Adversarial Networks (GANs). We will see the definition of these networks and how they are formed. We will also work on several real-world examples and applications of GAN. We will also explore one of the interesting applications of GAN called DeepFake. We will also discuss the elements that are required to manage a computer vision project.

## Learning Outcomes
- Discuss the Generative models.
- Discuss the Adversarial models.
- Implement GAN models and review some applications in real-world problems.
- Discuss the tools and guidelines to manage a successful machine learning project.
