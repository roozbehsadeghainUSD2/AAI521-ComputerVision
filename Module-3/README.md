# Module 3- Image Segmentation, Object Detection, and Classification
We will discuss the fundamentals of object detection and how it differs from picture classification in this module. We will go over image segmentation too and will see its importance in computer vision. You will look at various methods for object detection and image classification that build upon the foundation already established in the course. You will consider applications such as medical image interpretation and intelligent photo editing. The methods in this module are used in almost all computer vision problems.

## Learning Outcomes
- Develop and implement methods for image classification.
- Develop and implement methods for object detection.
- Develop and implement methods for image segmentation.
- Explain the difference between object detection and classification.
